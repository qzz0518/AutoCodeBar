The "ignore these apps" list for the Notification Center source is now an app picker.

- **Pick apps instead of typing bundle identifiers**: the list shows app icons and names; "Add App" offers a "Running Applications" submenu and "Choose from Finder…" for any .app; each row can be removed individually, and the defaults can be restored with one click.
